# Safelight Documentation

Safelight is a fast, project-based, GPU-accelerated RAW photo editor with an IDE-style extensible interface. The docs are split into two tracks:

## 📖 [User Guide](user/README.md) — using Safelight

For photographers. Installing the app, opening projects, culling, editing, exporting, and installing extensions.

- [Getting Started](user/getting-started.md) — first project to first export
- [Installation](user/installation.md) — desktop app and source builds
- [User Guide](user/user-guide.md) — every feature in detail
- [Using Extensions](user/using-extensions.md) — install and manage community add-ons
- [FAQ](user/faq.md) · [Changelog](user/changelog.md)

## 🛠 [Developer Docs](dev/README.md) — building for Safelight

For extension authors and contributors. The architecture, the extension authoring guide, and the full API reference.

- [Architecture](dev/architecture.md) — how the app is built
- [Building Extensions](dev/extensions/README.md) — anatomy, contributions, debugging, publishing
- [API Reference](dev/api/README.md) — the `SafelightAPI`, UI components, contribution signatures, stores, and types
- [Contributing](dev/contributing.md) — working on the core app
