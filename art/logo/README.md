# Safelight logo

All files here are generated by `build-logo.cjs` from Afacad Bold
(`source/Afacad-Bold.ttf`, SIL Open Font License 1.1, `source/OFL.txt`).
Edit the script, not the SVGs.

    npm i --no-save opentype.js
    node art/logo/build-logo.cjs

It also overwrites `public/favicon.svg`, `site/favicon.svg`, `art/favicon.svg`,
`art/Banner.png`, `site/wordmark.svg` and `site/shots/og-cover.jpg`. Then `npm run icon` rebuilds `build/icon.*` and the
installer bitmaps.

## Wordmark

`safelight.` in Afacad 700, lowercase, tracking -10/1000 em, the font's own
kerning. The dot of the i and the full stop are squares as wide as the font's
stem (the left stroke of "n"). The i's square is centred on its stem and sits
where the round dot's bottom edge was; the full stop uses the font's own
spacing after "t".

| File | Use |
| --- | --- |
| `safelight-wordmark.svg` | Primary, on dark backgrounds |
| `safelight-wordmark-on-light.svg` | On light backgrounds |
| `safelight-wordmark-mono-white.svg` | One colour, on dark |
| `safelight-wordmark-mono-black.svg` | One colour, on light |

- Clear space on every side: the height of the "s".
- Below 96 px wide on screen, use the icon instead.
- Don't recolour the letters red, stretch, add effects, or set the wordmark on
  a busy photo without a dark backing.

## Icon

"s." on a darkroom squircle (superellipse n = 5). The "s" x-height is 44% of
the tile; the group is centred on its bounding box.

| File | Use |
| --- | --- |
| `safelight-icon.svg` | 1024 master; also the favicons |
| `safelight-icon-32.svg` | Pixel-fitted, 24 and 32 px |
| `safelight-icon-16.svg` | Pixel-fitted, 16 px |

## Installer artwork

The Windows installer uses the landing site's print look (paper `#f3ece0`,
ink `#16110f`, red `#e5172f`):

- `installer-sidebar.svg` (164 x 340): the site hero's Tone curve and
  Histogram cards, for the welcome and finish pages.
- `installer-header.svg` (150 x 57): the on-light wordmark, right-aligned,
  for the inner pages.

`npm run icon` rasterises both at 100, 125, 150, 175, 200, 250 and 300 % into
`build/installer/`, and `build/installer.nsh` loads the one for the display's
scaling, so the art is never resampled.

The installer's text is set in its own copy of Afacad
(`build/installer-font/`, "Afacad Setup", line spacing tightened to fit
Windows' control heights), written by `python art/logo/installer-font.py`
(fontTools) when Afacad changes.
