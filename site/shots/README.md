# Site imagery

Drop the images below into this folder using these **exact filenames**. Until a
file is present the page falls back gracefully (GitHub-hosted screenshots for the
app scenes, a gradient for the hero plate), so nothing ever shows a broken image.

Photos → JPG (quality ~85). UI screenshots → JPG or PNG. Keep each file under ~600 KB.

| File              | What it shows                                   | Size (px)      | Ratio |
| ----------------- | ----------------------------------------------- | -------------- | ----- |
| `hero-plate.jpg`  | Dark, moody photo behind the hero (optional)    | 2560 × 1440    | 16:9  |
| `before.jpg`      | A flat, unedited RAW capture                    | 1800 × 1200    | 3:2   |
| `after.jpg`       | The **same frame**, developed in Safelight      | 1800 × 1200    | 3:2   |
| `library.jpg`     | Library / grid view — culling, filters          | 2560 × 1600    | 16:10 |
| `develop.jpg`     | Develop module — tone curves, HSL, color wheels | 2560 × 1600    | 16:10 |
| `masks.jpg`       | Local adjustments — masks, heal/clone           | 2560 × 1600    | 16:10 |
| `workspace.jpg`   | A custom docked layout / multi-monitor setup    | 2560 × 1600    | 16:10 |
| `og-cover.jpg`    | Social share card (link previews)               | 1200 × 630     | 1.91:1|

Notes:

- `before.jpg` / `after.jpg` **must be the same composition** — they sit under a
  drag-to-compare slider, so any framing mismatch is obvious. Shoot the "before"
  as the raw as-shot render and the "after" as your finished grade.
- App scenes (`library`/`develop`/`masks`/`workspace`) are shown full-bleed with a
  side scrim, so keep the important subject toward the **center / scrim-free side**
  (left edge is darkened on odd scenes, right edge on even scenes).
- `hero-plate.jpg` is dimmed to ~50% and slowly drifts — a high-contrast, dark
  image with empty mid-frame works best so the headline stays readable.
