EXTENSION REGISTRY

Registry requests

The registry decides which extensions in the open source extension library are verified, replaced, discontinued or banned. Fill in a form and GitHub opens with your request ready to submit. Each one becomes a pull request that a maintainer reviews.

Verify Replace Discontinue Category Report

FOR DEVELOPERS

Get an extension verified

A maintainer reads the code of the release you name. Once verified, Safelight shows the extension with a Verified badge and installs it without the unreviewed warning.

Verification covers that version only, so ask again for each release you want covered. The repository must be public, have the safelight-extension topic, and publish the version as a GitHub Release.

owner/repo, or the repository's GitHub URL.

The release to review. Leave it empty for the latest release.

What changed since the last verified version, the permissions it asks for and why.

GitHub opens with this filled in. Check it and submit there. You need a GitHub account.

FOR DEVELOPERS

Replace an extension

For an extension that moved to a new repository, or one another extension takes over from. Wherever the old one is installed, Safelight shows a Discontinued bar with Install replacement and Uninstall, and Browse stops offering it.

To also turn the old extension off for people who install the new one, add "supersedes": ["old-extension-id"] to the new extension's safelight.json.

owner/repo, or the repository's GitHub URL.

owner/repo, or the GitHub URL, of the extension that replaces it.

Shown on the Discontinued bar, at most 140 characters. Leave it empty for “No longer maintained.”

GitHub opens with this filled in. Tick “I maintain this repository” there and submit. You need a GitHub account.

FOR DEVELOPERS

Discontinue an extension

For an extension you no longer maintain and nothing replaces. Safelight shows a Discontinued bar with your message and Uninstall wherever it is installed, and Browse stops offering it. Nothing is removed from anyone's computer.

owner/repo, or the repository's GitHub URL.

Shown on the Discontinued bar, at most 140 characters. Leave it empty for “No longer maintained.”

GitHub opens with this filled in. Tick “I maintain this repository” there and submit. You need a GitHub account.

FOR DEVELOPERS

Set an extension's category

The library groups extensions by purpose. An extension normally names its own category, with a safelight-<category> topic or categories in its safelight.json, and those always win. This is for one whose author left it untagged.

owner/repo, or the repository's GitHub URL.

One to three, separated by commas: Library, Metadata, Tone, Colour, Looks, Detail and repair, Workflow, Export and sharing, Presets, Themes and interface.

GitHub opens with this filled in. Check it and submit there. You need a GitHub account.

FOR EVERYONE

Report an extension

Report an extension that harms people's photos, files or privacy. A banned extension can't be installed, and Safelight turns it off where it is installed. A maintainer checks every report before anything is banned.

Reports are private, so nobody is accused in public before a report is checked. Include the repository, what the extension does, the version where you saw it, and how to see it: files and lines, network requests, steps.

Report privately on GitHub
