01 / 08 · Reproducible RAW processing

Same file.
Same result.
Every time.

Safelight renders RAW the same way from the app or from a script. Every edit records the processing version it was made with, so a Safelight update never changes an old result. It runs offline, needs no account, collects nothing, and its source is open to audit.

02 / 08 · Specification

Spec sheet

Input
NEF, CR2, CR3, ARW, DNG, ORF, RAF, RW2 and more. JPEG, PNG, TIFF and HEIC.
Decode
Open source RAW decoding plus Safelight’s own linear-float decoder. Add your own decoder for any format.
Working space
Scene-linear Rec.709 before the display transform. Stages can work in Rec.2020.
Precision
16-bit GPU pipeline. One shader renders the preview, the thumbnail and the export.
Output
JPEG, PNG, WebP, and 8 or 16-bit TIFF in sRGB, Display P3, Adobe RGB or ProPhoto RGB, with an embedded ICC profile.
Metadata
Camera EXIF stays out unless you turn it on. GPS has its own switch. XMP is never copied.
Automation
The safelight command: JSON output, documented exit codes, batches from standard input.
Network
None required. The update check can be switched off.
Platforms
Windows, macOS (universal) and Linux: deb, rpm, pacman, Flatpak and AppImage.
Licence
GPL v3. No seats, no keys, no expiry.

04 / 08 · Reproducibility

Safelight updates never change an old edit.

Every edit stores the processing version it was made with. A new release renders new edits with the new version and old edits with their own, so last year's result renders the same today.

V1

Frozen

Edits from before versions existed. It never changes again.

V2

Current

Every new edit, with the full range kept through the display half.

V3

In development

Not given to new edits yet.

05 / 08 · Colour

A colour chain you can read.

Four documented steps from camera RGB to file, with every point where an extension can step in written down.

01

Input

Camera matrix and as-shot white balance. Out-of-gamut values are kept, not clipped.

02

Working

Linear Rec.709, scene-referred. Highlights above 1.0 survive.

03

Scene to display

A display transform chosen per photo, and replaceable by an extension.

04

Output

sRGB, Display P3, Adobe RGB or ProPhoto, with an ICC v2 matrix profile embedded.

07 / 08 · Deployment

Runs where your data has to stay.

Offline

No account and no cloud. Switch off the update check and nothing leaves the machine.

Portable

The catalogue is a folder of JSON beside the data. Copy the folder and the history comes with it.

Local view

Auditable
